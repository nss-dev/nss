# NSS 3.131.1 release notes

## Introduction

:::{container}
Network Security Services (NSS) 3.131.1 was released on *20 October 2026*.
:::

## Distribution Information

:::{container}
The HG tag is NSS_3_131_1_RTM. NSS 3.131.1 requires NSPR 4.39 or newer.

NSS 3.131.1 source distributions are available on ftp.mozilla.org for secure HTTPS download:

- Source tarballs:
  <https://ftp.mozilla.org/pub/mozilla.org/security/nss/releases/NSS_3_131_1_RTM/src/>

Other releases are available {ref}`mozilla-projects-nss-releases`.
:::

## Changes in NSS 3.131.1

- Bug 2083709 - Remove eMudhra emSign Root CA - C1 and emSign ECC Root CA - C3 from NSS.
