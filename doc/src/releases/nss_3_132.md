# NSS 3.132 release notes

## Introduction

:::{container}
Network Security Services (NSS) 3.132 was released on *21 October 2026*.
:::

## Distribution Information

:::{container}
The HG tag is NSS_3_132_RTM. NSS 3.132 requires NSPR 4.39 or newer.

NSS 3.132 source distributions are available on ftp.mozilla.org for secure HTTPS download:

- Source tarballs:
  <https://ftp.mozilla.org/pub/mozilla.org/security/nss/releases/NSS_3_132_RTM/src/>

Other releases are available {ref}`mozilla-projects-nss-releases`.
:::
